Platform User Guide
1. Home Dashboard

Overview of all system features, quick navigation to portals, and exam guidelines.

2. Board Result (All Boards)

Look up results for all Bangladeshi Education Boards (Dhaka, Rajshahi, Chittagong, etc.) via educationboardresults.gov.bd.

  • Requires: Roll, Registration, and Captcha.
  • Supports both single roll lookup and batch CSV/Excel upload.
3. Cumilla Board Result

Direct fast server connection to hscresult.comillaboard.gov.bd (HSC) and result19.comillaboard.gov.bd/SSCRCBY26/individual/ (SSC). Only Roll number is required! No registration number and no captcha needed.

4. Chattogram Board Result

Direct fast server connection to https://hscresult.bise-ctg.gov.bd/h22_31_x1_26/individual/ (HSC). Only Roll number is required! No registration and no captcha needed.

5. Result Analysis

Deep institutional performance dashboard: Subject-wise grade tables, student merit ranking, 1-subject and 2-subject fail lists, GPA distributions, and full multi-sheet Excel export.
