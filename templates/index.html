    How to Use & File Guide
    1. Batch File Preparation

    Upload a CSV (.csv) or Excel (.xlsx) file containing your student list.

    • Required column: Roll
    • Optional column: Registration (needed for general education board full marksheet)
    2. Direct Board Verification

    For Cumilla Board HSC, results are queried through the dedicated board result server using only the Roll number. For all other boards, results are verified via the standard Education Board portal.

    3. Analytics & Export Reports

    Once records are loaded, open Result Analysis to explore student merit positions, 1-subject and 2-subject fail breakdowns, GPA distributions, and download Excel/PDF reports.
